# ActionLens GPU 阶段接入清单

GPU 阶段的目标是先完成一个可复核的真实回合，再扩展到完整的 40 次评测。不要在单回合尚未稳定时直接开始批量运行。

## 开始条件

- 本地页面能够展示 40 条模拟记录；
- `schemas/run.schema.json` 已稳定；
- 真实结果导入器测试通过；
- 已确定两个 LIBERO 候选任务；
- 已准备云端持久化数据盘和本地备份目录；
- 已明确服务器停止计费的方法。

## 云端环境准备

- 使用 Linux 和 NVIDIA GPU；
- 将项目克隆到持久化目录；
- 为 Python 依赖创建独立虚拟环境；
- 配置无显示器的仿真渲染；
- 将模型缓存放在持久化数据盘；
- 不把 Hugging Face Token 写入仓库或日志；
- 安装完成后保存云端镜像或快照。

## 适配器实现

真实评测只需要实现三个现有协议：

1. `LiberoEnvironment` 实现 `Environment`；
2. `SmolVlaPolicy` 实现 `Policy`；
3. `SmolVlmDiagnoser` 实现 `Diagnoser`。

适配器输出统一的 ActionLens 记录，不把 LeRobot 或 PyTorch 对象传给前端。

## 单回合验收

- 固定一个任务和一个随机种子；
- 记录原始语言指令；
- 保存环境成功状态和终止原因；
- 保存实际步数与运行耗时；
- 生成完整 MP4 视频；
- 提取开始、中间和结束关键帧；
- 生成符合 Schema 的 `metadata.json`；
- 下载到本地并通过真实结果导入器。

单回合导入成功并能在详情页播放后，才进入下一步。

## 小规模测试

在正式评测前运行四个回合：

| 任务 | 正常条件 | 扰动条件 |
|---|---:|---:|
| 任务 A | 1 | 1 |
| 任务 B | 1 | 1 |

检查任务 ID、动作格式、随机种子、视频、成功状态和异常记录是否完整。

## 正式评测

- 两个任务分别运行正常条件 10 次；
- 两个任务分别运行扰动条件 10 次；
- 正常与扰动条件使用相同种子；
- 每个回合结束后立即保存记录；
- 支持根据 `runId` 跳过已经完成的回合；
- 异常和中断必须保留，不能从总数中删除；
- 运行结束后先备份，再释放云端实例。

## VLM 分析

- VLA 批量运行结束后再加载 VLM；
- 从完整结果中选择约 30 帧；
- 输出结构化诊断；
- 无法判断时使用未知状态；
- 人工核对目标可见性、位置和失败阶段；
- 至少整理 3 个具体失败案例。

## 本地导入

将云端输出下载到 `incoming/` 后执行：

```powershell
.\.venv\Scripts\python.exe scripts\import_real_results.py incoming\libero-evaluation
```

导入成功后重新启动或刷新 React 页面。页面右上角应显示“真实评测数据”。

## 完成条件

- 至少一个真实回合可以复现并播放；
- 40 次真实运行具有完整结构化记录；
- 成功、失败、异常和中断分别统计；
- 视频和关键帧路径全部可访问；
- VLM 结果与人工复核结果同时保留；
- README 中记录实际模型版本、环境版本和评测命令。
