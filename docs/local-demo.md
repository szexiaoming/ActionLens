# ActionLens 本地演示说明

本地演示用于展示评测产品流程，不代表真实模型效果。演示前确认页面右上角显示“模拟数据”。

## 演示前准备

```powershell
.\.venv\Scripts\python.exe scripts\generate_mock_data.py
cd web
npm run dev
```

浏览器打开 `http://localhost:5173`。

## 建议演示顺序

1. 在总览页说明共有 40 次计划运行，并展示成功次数与总次数；
2. 对比正常画面和亮度扰动下的成功次数；
3. 在运行记录中选择任务 A、亮度扰动和失败状态；
4. 打开一条失败记录，查看任务指令、步数和终止原因；
5. 指出视频和关键帧尚未生成，页面能够保留缺失状态；
6. 查看模拟 VLM 诊断和人工复核分类；
7. 切换到诊断缺失记录，展示错误状态处理；
8. 强调真实结果接入后不需要重写页面。

## 演示中的必要说明

- 当前数字来自固定模拟数据；
- 任务成功最终由 LIBERO 判断；
- VLM 只辅助分析失败原因；
- GPU 阶段会用真实视频和结果替换模拟记录。
